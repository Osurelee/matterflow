## 版本方向

- V1：个人事项与分发跟进、完整正文、图片/录音、小步骤、任意深度独立事项主层级与跨位置引用、项目推进、回顾及多端可靠使用。
- V1.1：完整离线队列、系统提醒、语音转写及其他经验证增强。
- 更远期：重复模板、更多视图和智能拆解；多人协作需另行明确需求，不作为默认路线。
- V3：重复事项、自然语言辅助录入、拆解与复盘建议。
