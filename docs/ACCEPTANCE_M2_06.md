# M2-06 加载、空状态与保存失败体验验收

状态：实现、隔离回归及真实浏览器复核通过。验证命令：`npm run test:m2`（生产构建 + 隔离 API 集成套件），另在隔离数据库上启动生产进程做浏览器复核。未操作正式数据库或公网入口。

## 交付

- 列表加载显示骨架屏；空列表区分“收件箱已清空”和“还没有事项”，并提供新增入口；读取失败显示错误与“重试”。
- 详情加载显示读取中状态；详情读取失败显示错误与“重试”；不出现空白面板或假数据。
- 保存失败保留输入：标题、安排字段、等待/取消原因、追加进展在失败后都保留用户输入，错误区提示“输入已保留，可修改后重试”。
- 校验失败返回 `fieldErrors`，前端据此提示，且失败请求不写入数据、不产生事件。
- 版本冲突返回409并附 `currentVersion` 与当前对象，界面不自动覆盖。
- 未保存离开保护：关闭详情、退出登录和浏览器离开（beforeunload）在有未保存修改时都会提示；取消后输入保留。

## 验证

- `npm run typecheck` 通过。
- `npm run test:m2` 通过；新增 M2-06 回归覆盖：空标题、非法优先级、非法日期、空进展、缺少等待/取消原因、越权字段均返回对应 `fieldErrors`，且失败后数据行数、版本与事件数不变；过期版本返回409并附当前版本与对象。
- 真实浏览器复核（隔离库、生产进程）：登录后显示空状态；快速新增后打开详情，确认“安排与执行”“追加进展”“历史时间线”和新事件渲染；修改标题后关闭详情弹出未保存提示，取消后输入保留；模拟网络失败保存时显示错误与保留提示且版本不变；恢复后保存成功版本递增；刷新页面后新标题仍在。
