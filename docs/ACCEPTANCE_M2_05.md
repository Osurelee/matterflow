# M2-05 历史时间线与追加进展验收

状态：服务端、详情页及隔离回归通过。验证命令：`npm run test:m2`（生产构建 + 隔离 API 集成套件）。未操作正式数据库或公网入口。

## 交付

- 新增 `GET /api/tasks/:id/events`：按 `limit`（默认50、上限100）返回最近事件页，使用 `before`/`beforeId` 游标读取更早事件；响应按时间正序返回，并给出 `hasMore`。
- 新增 `POST /api/tasks/:id/progress`：在版本化幂等请求中追加文字进展；去空白后必填、上限5000码点，写入 `task_progress_appended` 事件并递增 version。
- 时间线展示事件类型、发生时间与字段变化摘要（含状态中文名、旧值→新值）；进展按纯文本展示。
- 历史不可改写：`task_events` 由数据库触发器禁止 UPDATE/DELETE，回归包含直接改写的拒绝断言。
- 已归档事项只读：可读取历史，但追加进展返回409；已删除事项在时间线与进展接口均返回404，不在回收站外暴露。

## 验证

- `npm run typecheck` 通过。
- `npm run test:m2` 通过，覆盖：时间线按时间正序且首条为创建事件、空进展与超长进展被拒、有效进展持久化并新增事件、同 requestId 重放不重复写入、过期版本返回409、归档写入409、删除后404，以及事件表改写被拒。
