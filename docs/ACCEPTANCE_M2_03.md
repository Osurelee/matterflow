# M2-03 事项状态流转验收

状态：实现及隔离回归通过。验证命令：`npm run test:m2`（生产构建 + 隔离 API 集成套件）。测试未使用正式数据库、账号或公网映射。

## 交付

- 新增 `POST /api/tasks/:id/transition`，请求使用 `requestId` 与 `expectedVersion`；服务端事务内校验所有权、删除/归档状态、空间/项目归档状态及合法状态转换。
- 实现状态机：待处理 → 进行中/等待中/已完成/已取消；进行中 → 待处理/等待中/已完成/已取消；等待中 → 待处理/进行中/已完成/已取消；结束状态只能重新打开为待处理。相同状态及其他非法转换返回409。
- 进入等待中必须填写等待原因；取消必须填写取消原因；均由服务端按码点校验长度并拒绝空白值。
- 完成/取消记录结束时间、自动标记已整理、清空当前跟进与阻塞，并将当前行动方设为无人；等待原因随离开等待而清除。存在有效委托时，结束动作在同一事务内结束委托并记事件。
- 重新打开清除结束时间、取消原因、结果说明、阻塞与当前跟进，恢复本人行动；若事项此前已归档则同时取消事项归档；不恢复旧委托。
- 每个有效流转递增 version 并追加 `task_transitioned` 事件；写入事件和幂等请求记录与数据变更原子提交。重试复用原响应，不产生重复事件。
- 详情面板展示当前状态原因，并提供合法目标状态选择与所需原因输入。
