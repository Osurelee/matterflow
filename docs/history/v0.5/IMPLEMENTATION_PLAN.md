## 1. 推进方法

每次选一个里程碑中的可交付任务，注明需求编号、改动范围和验收结果。完成意味着实现、验证、记录都到位；界面能点击但数据未持久化不算闭环完成。

主依赖：M0 → M1 → M2 → M3 → M4 → M5 → M6。M0的远程网络验证可与本地开发并行推进，但未通过不能宣称多端远程可用。M1建立备份基础，M6完成正式恢复验收。
