# M5-05 验收记录：项目主树、聚焦与叶子进度

日期：2026-10-13  
状态：已完成本机隔离验收；正式库、真实设备与公网仍待后续阶段。

## 交付范围

- 新增 `GET /api/projects/:id/overview`，按项目根的递归主关系计算项目进度。
- 新增 `GET /api/projects/:id/tree`，默认读取项目根的直接主子项，使用 `parentId` 按需读取任意深度节点。
- 项目页接入主树面板，支持展开/收起、打开事项、聚焦到任意节点及回到项目目标。
- 统计只读取未删除、未归档主树；项目根自身不计入叶子，引用关系不进入主树统计。
- 有效叶子定义为没有未删除直接主子项的事项；活跃但全部后代已结束的非叶节点单列为“待核实成果”。
- 空项目显示“尚未拆解”，不会把空进度显示成 0%。

## 统计口径

项目进度分别返回 `active`、`completed`、`cancelled`、`needsReview`、`leafTotal` 和 `completionPercent`。完成百分比只按有效叶子计算；活跃的待核实父项不重复计入叶子，但其已经结束的叶子后代仍属于有效叶子。

树接口只允许访问当前项目根的递归主子树；越权或不属于该树的 `parentId` 返回 `PROJECT_TREE_OUT_OF_SCOPE`，非法查询参数返回 `INVALID_INPUT`。
