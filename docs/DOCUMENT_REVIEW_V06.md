## 3. 交叉审查后修正

| 问题 | 最终口径 |
| --- | --- |
| 子全结束后父核实动作被叶子过滤隐藏 | 待核实父进入行动集合；仍有活跃子项的到期父另给不计数提示 |
| 项目结束仅检查叶子，可能跳过父成果 | 所有未删除事项（含父）须结束；进度统计仍只算有效叶子 |
| 结束项目再次产生活跃工作 | 先显式重开项目active，新增/移入/重开均守卫 |
| 软删除唯一子项后父从列表消失 | 有效叶子按未删除子项定义 |
| 整树恢复复活此前独立删除子项 | 删除批次记录实际集合，只恢复本批，单子恢复校验父/容器 |
| 已结束事项编辑归属绕过层级 | 整树迁移/解父/目标项目守卫同样适用 |
| 项目内媒体捕获默认整理冲突 | 所有媒介都按入口：全局未整理、项目内已整理 |
| 多份新建媒体草稿没有taskId | captureDraftId稳定识别，编辑草稿另带taskId/baseVersion |
| 批量捕获部分成功未定义 | 最多50条、整批预校验和原子提交，校验失败全不保存 |
| staging租约未定义 | 首版无服务器租约，24小时未关联过期，本机保留原稿/提示重传 |
| 进展发生时间与记录时间混淆 | 按服务器记录时间，补录日期写在文本 |
| 导出范围缩写丢失旧保证 | 全业务JSON含归档/删除、修订/清单/元数据；CSV当前筛选；bundle含二进制；排除凭据/草稿/staging |
