# M6 验收记录：行动回顾、搜索、生命周期与导出

日期：2026-10-14  
状态：已完成本机隔离验收；正式库、真实设备、公网和大数据量性能仍按 M7/M8 门槛执行。

## 交付范围

- M6-01：新增“今天 / 已逾期 / 待跟进”视图；以 Asia/Shanghai 计算日边界，活跃父项在存在活跃后代时不重复展示；跟进日期支持“推迟到明天 / 下周一”快捷操作。
- M6-02：新增全局中文搜索，覆盖标题、正文、进展、处理方和 ready 附件名；返回命中来源和完整主路径；搜索按 owner 隔离，并排除归档/删除事项。
- M6-03：新增未整理、等待未设跟进、项目无下一步、已完成、已取消五类回顾；完成/取消优先展示成果或取消原因。
- M6-04：补齐归档、取消归档、回收站、恢复的前端入口；历史列表只展示批次根事项，归档/删除事项可打开只读历史时间线，删除历史通过显式 `includeDeleted=true` 读取。
- M6-05：新增 JSON、CSV、ZIP bundle 导出；JSON 无筛选参数时导出完整业务快照并保留归档/删除状态，显式筛选时导出筛选范围；CSV 做公式前缀防护；bundle 包含 JSON、CSV、manifest、校验后的 ready 媒体二进制。
- M6-06：完成内容搜索、主层级路径、日期视图、回顾、生命周期恢复和导出的端到端隔离验收。

## 前端交互

- 顶部搜索框支持提交、分页、命中来源展示和打开事项。
- 搜索结果改为只读上下文卡片，展示命中字段、主路径和来源；不在缺少版本信息的结果行上提供编辑控件。
- 工作台导航增加逾期、待跟进及五类回顾入口；回顾项可直接打开事项详情。
- 已完成事项详情支持补充成果说明，保存后即时回写当前回顾卡片；取消原因和跟进日期以同样的结果上下文展示。
- 导出面板沿用当前空间/项目/视图/搜索范围，提供 JSON、CSV、完整 bundle 三种动作。
- 归档与回收站保持只读列表，恢复或取消归档后自动刷新；历史时间线在只读弹层中展示。
- 日期编辑器在跟进字段旁提供明确的延期快捷操作，保存反馈仍在属性弹层附近完成。
- 工作台普通列表中的状态、日期、处理方式修改后会立即重载当前视图，避免风险标记和列表归属滞后。
