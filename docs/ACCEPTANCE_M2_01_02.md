# M2-01 / M2-02 收件箱与快速事项切片验收

日期：2026-10-12。状态：本机隔离回归通过。未对正式数据库、正式账号或公网映射执行操作。

## 已交付

- 响应式现代工作台：桌面侧栏、手机底部导航、真实的“收件箱/全部事项”切换、快速新增入口、键盘快捷键 `⌘/Ctrl+K`。
- 收件箱完全由数据库驱动，不再使用硬编码示例：只显示活跃且未整理的事项；“全部事项”显示未归档、未删除的事项。
- `GET /api/tasks?view=inbox|all&limit=...&offset=...`：分页、稳定排序、总数、会话 owner 隔离、`no-store`。
- `GET /api/tasks/:id`：只读当前 owner 的事项详情。
- `POST /api/tasks`：只需 `requestId + title`；未提供空间时，服务端选本人默认私人空间。数据库默认待处理、未整理、本人负责和本人行动。
- `PATCH /api/tasks/:id`：标题编辑，使用 `expectedVersion` 和幂等 requestId。
- `POST /api/tasks/:id/process`：事务内标记已整理、递增 version、追加 `task_processed_marked` 事件并记幂等结果。整理后从收件箱消失，仍在全部列表。
- 新建、标题编辑与整理写入均保留请求状态；错误时留在页面并显示错误，不展示虚假成功。
